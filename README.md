## Опис роботи

У межах лабораторної роботи виконано алгоритмічний рефакторинг п'яти фрагментів коду із заміною повторного лінійного пошуку по списках на структури швидкого пошуку (`dict` та `set`):
1. **Фрагмент 1** — переписано з вкладеного перебору списку клієнтів $O(N \cdot M)$ на словник `clients_by_id` за ключем `client.id` зі складністю $O(N + M)$.
2. **Фрагмент 2** — перевірку заблокованих клієнтів у списку `blocked` замінено на пошук у множині `set(blocked)` за $O(1)$.
3. **Фрагмент 3** — підрахунок кількості замовлень кожного клієнта переписано з вкладеного циклу $O(N^2)$ на словник лічильників `counts_by_client` за ключем `order.clientId` із збереженням початкового порядку появи клієнтів.
4. **Фрагменти 4 та 5** — залишено без змін як приклади задач, де нова структура даних не потрібна (пошук максимуму за один прохід та помилкове створення словника всередині циклу).

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab08`:
   ```bash
   cd lab08
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab08.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab08.py`)*
